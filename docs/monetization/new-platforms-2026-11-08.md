## Вывод

Все найденные self-serve регистрации упираются в **капчу** (BingX — слайдер,
LeadBit — hCaptcha, CoinW — капча) или **email-код**. Автоматически не пройти —
нужен человек, который решит капчу в окне; после этого я доделываю регистрацию
(код из Gmail), заполняю партнёрскую анкету и сохраняю реф-ссылку.

## Что подготовить (по приоритету)

1. **BingX** — окно с предзаполненными email/паролем; пользователь решает
   слайдер-капчу → я подтверждаю код из Gmail → заявка в affiliate-программу.
2. **CoinW** — аналогично (email/пароль предзаполнены).
3. **LeadBit** — нужен Telegram-хэндл для формы + hCaptcha.
4. **Phemex** — через NL-прокси.
5. **Pictory** — анкета (AI-видео): заполнить вручную по шаблону.
