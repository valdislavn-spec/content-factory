# Проект «Deals Factory» — товарные партнёрки в контент-заводе

Дата: 09.11.2026. Статус: концепт + план запуска.
Связанные документы: `product-affiliates.md`, `referral-links-register.md`.

## 1. Идея

Отдельное направление внутри завода: **рубрика товарных находок и deals-постов**,
которая монетизируется товарными партнёрками (Temu, Banggood, Sugargoo, AliExpress,
Shein, LightInTheBox). Не новый бренд с нуля, а:

1. **Сначала** — рубрика «Deals» / «Ofertas» в существующих каналах (трафик уже есть):
   `tech-ai-es` и `ai-news` — гаджеты, `futbol-es` и `sport-news` — форма/бутсы/экипировка;
2. **Потом** — выделенные каналы, если рубрика даст клики:
   «Deals EN» и «Ofertas ES» (аудитория, которая подписалась именно на находки).

Почему так: товарные посты дешевле в производстве, чем новости, не требуют 18+,
дают второй источник дохода помимо крипто-бирж и беттинга, и их можно ставить
до 1 поста на 3–4 новостных без раздражения аудитории.

## 2. Формат поста (3 варианта)

### A. «Находка дня» (основной, 1 товар)
```
🛒 {{Заголовок: что это и зачем}}

Цена: ~~{{старая}}~~ → {{новая}} ({{скидка}}%)
{{1 строка: для кого/к какому событию}}

👉 {{SHORTLINK}}
⚠️ Партнёрская ссылка. Цена на момент публикации.
```

### B. «Подборка 3–5 товаров» (для тематических каналов)
```
🔥 5 находок недели: {{тема}}

1. {{товар}} — {{цена}} → {{short}}
2. ...
⚠️ Партнёрские ссылки.
```

### C. «Как заказать из Китая» (для агентов, maks конверсия в ES)
```
👕 {{товар}}: {{цена}} через агента

• как заказать: {{3 шага}}
• сроки/доставка в ES/LatAm
👉 {{sugargoo link}}
```

Правила: 1 товарный пост на 3–4 обычных; ссылки через shortlink + UTM
(`utm_campaign=deals_<program>`); маркировка «партнёрская ссылка/advertising»;
цены с оговоркой «на момент публикации».

## 3. Источники товаров

| Источник | Что берём | Статус |
|---|---|---|
| **Temu** | гаджеты, товары для дома, мелочи < $10 — вирусные находки | партнёрка своя (до 35%), регистрация блокируется IP; пойдём через Admitad |
| **Banggood** | RC/FPV-дроны, электровелосипеды, гаджеты, инструмент | своя партнёрка до 25% (письмо в поддержку отправлено); оффер Banggood WW в Admitad (EPC ~$2) |
| **Sugargoo** | форма/бутсы/гаджеты из Китая «через агента» | ✅ подключён: `sugargoo.com/register?memberId=2834487856253302865`, 4–9% |
| **AliExpress / Shein / LightInTheBox** | масс-маркет товары, одежда, аксессуары | через Admitad (после верификации площадки) |
| **eBay / KLEKT / Amazon** | экипировка, кроссовки, техника | второй эшелон (eBay капча, Amazon — отдельная регистрация) |

Товары подбираем вручную (куратор) или полуавтоматом: парсим топ-скидки
партнёрского кабинета/фида и складываем в очередь на модерацию.

## 4. Каналы и календарь (первые 4 недели)

| Неделя | `tech-ai-es` | `futbol-es` | `ai-news` / `sport-news` |
|---|---|---|---|
| 1 | 2 deals-поста (Sugargoo: гаджеты; временная заглушка Temu) | 1 пост «форма через агента» + 1 бутсы | 1 подборка гаджетов |
| 2 | 2 поста (Temu/AliExpress после Admitad) | 2 поста (Sugargoo) | 1 подборка |
| 3 | 3 поста | 3 поста | 2 поста |
| 4 | 3 поста + закреп «Ofertas» | 3 поста + закреп | 2 поста |

Дальше — если CTR по UTM > 1% и есть продажи, запускаем выделенные каналы
«Deals EN» / «Ofertas ES» с той же сеткой 3–5 постов в день.

## 5. Техника (используем существующий завод)

1. **Конфиг канала/рубрики** — `config/channels.deals.yaml` (id, язык, формат A/B/C,
   список программ, лимит ссылок).
2. **Очередь товаров** — `data/deals/queue.yaml`: `{program, title, price, old_price,
   url, channel, hook}`; скрипт `scripts/deals_queue.py` добавляет/валидирует.
3. **Генератор поста** — `scripts/deals_post.py`: шаблоны A/B/C + LLM-хук (1–2 строки
   на языке канала), подстановка shortlink + UTM, проверка «нет запрещённых обещаний».
4. **Публикация** — существующие publishers (Telegram/VK), расписание из content-factory.
5. **Учёт** — клики по UTM в GA4, комиссии в кабинетах программ; еженедельный отчёт
   `scripts/deals_report.py` (клики, EPC, доход по программам).

## 6. Экономика (реалистично)

- Товарные клики в Telegram: CTR на канал ~0.5–2% от охвата поста.
- EPC ориентиры: Temu ~$0.3–1, Banggood ~$2 (Admitad), Sugargoo — % от доставки
  (средний заказ $30–80 → 4–9% от доставки ~$20–40 = $1–3/заказ).
- Цель первого месяца: 20–30 deals-постов, 300–600 кликов, 5–15 продаж,
  **$30–100 комиссии**; окупаемость — ноль затрат, только время.
- Масштаб: если рубрика даёт >1% CTR, выделенные каналы и 5 постов/день → x5–10.

## 7. Риски и обходы

- **Temu** блокирует прокси/IP → подключаемся через Admitad (площадка уже создана,
  ждёт Telegram-верификацию) или через резидентный IP.
- **Banggood** закрыл самостоятельную партнёрку («policy reasons») → ждём ответ
  поддержки (3–5 дней) + оффер Admitad.
- **Аудитория** каналов про новости может не любить товарные посты → правило
  1 к 3–4, только тематические товары, честные цены.
- **Комплаенс**: маркировка рекламы, без «гарантий дохода», актуальность цен.
