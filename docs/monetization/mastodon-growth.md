# Программа роста Mastodon

Скрипт: `scripts/mastodon_growth.py`, конфиг: `config/mastodon_growth.yaml`,
автозапуск: `.github/workflows/mastodon-growth.yml` (ежедневно 16:17 UTC).

## Что делает

1. **Подписки** — находит активных авторов по хэштегам `#bitcoin #crypto #ai
   #travel #fediverse` (свежие посты ≤72 ч), фильтрует ботов/закрытые/пустые
   профили, подписывается до 20 в день с паузой 3 с.
2. **Хэштеги** — подписывается на те же теги, чтобы лента приносила темы.
3. **Бусты** — бустит 5 постов в день (не репосты, не NSFW, ≥1 лайк,
   англ/исп), чтобы аккаунт был заметен авторам.

Состояние (кого уже подписали/забустили, дневные лимиты) — в
`data/mastodon_growth_state.json`, в CI кэшируется между запусками.
Запуск вручную:

```bash
python scripts/mastodon_growth.py --all --dry-run   # посмотреть
python scripts/mastodon_growth.py --follow          # только подписки
python scripts/mastodon_growth.py --all             # всё
```

## Правила, чтобы не забанили

- не более 20 подписок и 5 бустов в сутки;
- паузы между действиями (3–4 с);
- никаких массфолов/автоответов/спама ссылками;
- релевантность: крипто/AI/travel/fediverse, живые профили.
