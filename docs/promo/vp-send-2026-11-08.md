# ВП-рассылка: как отправить предложения владельцам каналов

Дата: 08.11.2026. Цель — обмен рекламой (ВП) с каналами своей тематики.

## Важно: кто может писать первым

**Бот не может** написать первым чужому владельцу канала — Telegram это
запрещает. Писать нужно с **аккаунта человека** (владельца сети) — либо вручную,
либо через user-session (Telethon) в GitHub Actions.

## Вариант 1 — вручную (сегодня, 10 минут)

1. Откройте `docs/promo/outreach-tracker.csv` — цели со статусом `prospect`.
2. Возьмите сообщение из dry-run:
   ```bash
   python scripts/vp_outreach.py --region en --limit 5   # EN-цели (крипто)
   python scripts/vp_outreach.py --region es --limit 5   # ES-цели (спорт)
   ```
3. Отправьте каждому в Telegram по одному сообщению (не более 5 за час),
   дождитесь ответа 2–3 дня, только потом напоминание.
4. После публикации обмена — заполните трекер: `date_posted`, ссылки,
   `subs_delta_48h`.

## Вариант 2 — автоматически (Telethon в GitHub Actions)

Нужны 3 секрета в репозитории (Settings → Secrets and variables → Actions):
`TG_API_ID`, `TG_API_HASH`, `TG_SESSION` (StringSession аккаунта владельца).

Затем: Actions → **vp-outreach** → Run workflow:
- `region`: en / es / all;
- `limit`: 1–5;
- `dry_run`: сначала `true` (только лог), потом `false` (отправка).

Скрипт сам выбирает оффер: 1:1 для сравнимых, 2:1 для крупных каналов,
для ES — 1:1 или платный тест $3–8. Между сообщениями пауза 20–45 с.

## Сканирование ES-кандидатов

При изменении `docs/promo/partner-candidates-es.txt` автоматически запускается
workflow **partner-scan-es**: проверяет каналы через t.me/s (просмотры/посты/
накрутка) и выкладывает отчёт в артефакты. Прошедшие отбор — добавляем в
трекер и пишем им.

## Правила (чтобы не получить бан)

- 3–5 новых контактов в день максимум; один и тот же текст не спамить.
- 2–3 обмена/нед на канал; пост держать 24–48 ч.
- Никаких казино/скама/«гарантированных прогнозов»; для ставок — 18+.
- Если не ответили за 3 дня — одно вежливое напоминание, затем не трогать.
