# Эксперименты роста (бесплатные, бюджет $0)

Правила: один эксперимент — одна метрика; длительность ≥ 5–7 дней; решение
принимаем по просмотрам/подписчикам (не по ER — реакции частично покупные).
Данные: `growth-raw-*.json` (ветка `growth-reports`) + Bot API.

## 1. Опросы вместо покупных реакций

Гипотеза: опросы дают честную вовлечённость и возвраты в канал.

- 1 опрос в день в **Crypto & Blockchain** (в слоте с максимумом просмотров).
- Вопрос по горячей теме дня, 2–4 варианта, анонимный, без «правильного».
- Через 24 ч: `python scripts/post_poll.py --channel crypto-news --check <message_id>`
  → голоса/просмотры. Записать в таблицу ниже.
- Метрики: голосовавшие/просмотры, комментарии под опросом, прирост подписчиков
  за сутки опроса против обычного дня.

| Дата | Вопрос | Голоса | Просмотры | Голоса/просм | Δ подписчиков |
|---|---|---|---:|---:|---:|

## 2. CTA «поделиться» в конце поста

- Неделя A: посты с явным CTA («Share with a friend…»), неделя B — без.
- Метрика: средние просмотры/пост и прирост подписчиков (Bot API снимки).
- Учёт: `growth-report` пишет подписчиков ежедневно; сравнить недели.

## 3. Время публикации

- Две группы слотов: 08–10 ET (утро США) и 18–21 ET (вечер США).
- 7 дней: посты только в одной группе, затем 7 дней в другой.
- Метрика: средние просмотры/пост из `growth-raw` (фильтр по часу).

## 4. Кросс-промо crypto → AI/Sports

- Каждый вторник/пятницу (workflow `cross-promo`) фиксировать дельту
  подписчиков целевого канала за 48 ч по `growth-report`.
- Сравнить с обычными днями. Если дельта ≈ 0 после 4 постов — сменить текст/
  канал (люди из крипты лучше конвертятся в AI, чем в спорт).

## 5. Дистрибуция: ВП и каталоги

- ВП: 3–5 обменов/нед; партнёров ищем `scripts/partner_scan.py` + workflow
  `partner-scan`, ведём `docs/promo/outreach-tracker.csv`.
- Каталоги: TGStat, Telemetr, Tlgrm — подаём 1 раз, проверяем трафик по
  росту подписчиков в дни после публикации.
- Метрика: подписчики/неделя до и после; стоимость $0.

## Как читать результаты

- Подписчики: Bot API `getChatMemberCount` (в `growth-report`).
- Просмотры/посты: `t.me/s` в Actions → `growth-raw-*.json`.
- ER **не используем**: реакции в каналах покупались; после отказа от накрутки
  через 2–4 недели можно ввести «честный ER» по комментариям/пересылкам.
