# X promo series: SEO, metadata, subscriber acquisition

Файл серии: `config/x_promo_series.yaml`.
Скрипт: `scripts/x_promo_series.py`.

## Что применено в каждом посте

- **SEO-хук**: ключевая фраза в первой строке (`crypto news`, `AI news`, `US sports`, `cheap flights`).
- **Метаданные**: тематические хэштеги (1–2), эмодзи-рубрика, явный CTA.
- **UTM**: ссылка на travel-хаб содержит `utm_source=x&utm_campaign=x_promo`.
- **Соцдоказательство/конкретика**: частота обновлений, источники, формат «что внутри».
- **Снижение трения**: прямые ссылки на Telegram и партнёров, без промежуточных форм.
- **Кросс-промо**: каждый канал упоминает сеть, чтобы подписчик нашёл остальные.
- **Рост через репост**: в постах-анонсах есть `Follow + repost`.
- **Комплаенс**: `Ad`, `Not financial advice`, `18+`, `No win, no fee may apply`.

## Расписание

2 поста в день, 16:00 и 22:00 UTC. Первый пост можно опубликовать сразу,
остальные — `customScheduled` через Buffer.
