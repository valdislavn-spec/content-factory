# ВП и бесплатное продвижение (EN + ES)

Взаимный пиар (ВП, cross-promo) — обмен постами с равным по охвату каналом.
Дешёвый и безопасный способ добрать первых подписчиков, пока сеть маленькая.
Бюджет: **$0–10**, цель — не «накрутить цифры», а найти повторяемые каналы,
которые дают переходы.

## Правила (нарушение = бан канала и потеря репутации)

- Только по согласию обеих сторон. Никакого спама админам и «бартера с ботами».
- Сопоставимый охват (средние просмотры), а не подписчики. Неравный обмен
  предлагайте с компенсацией (2 поста за 1) или отказывайтесь.
- 2–3 обмена в неделю на канал — больше выглядит как накрутка.
- Нативный пост: польза для читателя, ссылка в конце; не «подпишись на нас».
- Пост не удаляется раньше оговорённого срока (обычно 24–48 часов).
- Никаких казино, ставок, «инвестиций с гарантией», накрутки.

## Критерии партнёра

| Параметр | Значение |
|---|---|
| Тематика | пересекается на 50%+: AI∩crypto, tech∩AI, sport∩US sports, cripto∩finanzas |
| Средние просмотры | 300–3 000 (сопоставимо с нашими) |
| Частота | ≥ 3 постов/сутки, канал живой (посты за последние 3 дня) |
| ER | реакции/просмотры ≥ 1–3% (выше 30% — подозрение на накрутку) |
| Регион/язык | EN → US-аудитория; ES → ЛатАм (MX/AR/CO) |
| Безопасность | нет казино/ставок/скама, публичный, репутация чистая |

## Где искать партнёров

- **TGStat**: https://tgstat.com/search — поиск по ключам «AI news», «crypto
  news», «NFL», «inteligencia artificial», «criptomonedas», «fútbol»; смотреть
  «похожие каналы» у конкурентов.
- **Telemetr**: https://telemetr.io/ — карточки и похожие каналы, есть динамика.
- **Tlgrm.eu**: https://tlgrm.eu/channels — EN-каталог.
- **@crossmatch_bot** — матчинг по тематике/охвату, переговоры только по
  взаимному интересу.
- **Комментарии** под постами крупных тематических каналов — от имени канала,
  экспертно, без ссылок.

## Шаблон первого сообщения (EN)

```
Hi! I run AI News (@AINEWS0007) — AI news for a US audience, ~N views per post.
I'm looking for a cross-promo: one native post each, same day, comparable reach.
I'd post your channel as a useful resource in my next AI story, and you'd get a
short intro in yours. Happy to send our stats and a draft first.
Interested?
```

## Шаблон первого сообщения (ES)

```
¡Hola! Llevo ES AI News (@WORLDNews0007) — IA en español para LatAm, ~N
visualizaciones por post. Busco un cross-promo: un post nativo cada uno, el
mismo día, con alcance similar. Te paso nuestras estadísticas y un borrador del
texto, y tú decides. ¿Te interesa?
```

## Формат поста-обмена

EN (для партнёра, в нашем канале):
```
Если следите за <тема> — рекомендую <канал партнёра>: <1 предложение пользы>.
→ https://t.me/<partner>
```

ES:
```
Si sigues <tema>, te recomiendo <canal>: <una frase de utilidad>.
→ https://t.me/<partner>
```

## Как измерять эффект

1. До обмена зафиксируйте подписчиков (ежедневный growth-отчёт уже присылает).
2. Через 24–48 часов после обмена — посмотрите Δ подписчиков в
   `data/reports/growth-YYYY-MM-DD.md` / сводке в Telegram.
3. Записывайте результат в `docs/promo/outreach-tracker.csv`.
4. Повторяйте только партнёров, дающих ≥ +5 подписчиков; остальных — в архив.

## Бюджет $10

- Telegram Ads **не подходит**: минимальные бюджеты и CPM сильно выше $10.
- После 2 недель бесплатных механик можно купить 1–2 посева в маленьких
  каналах (500–2 000 подписчиков) по $3–8 за пост — только там, где тематика
  совпадает на 100%.
- Каталоги — бесплатно. Всё остальное — время, а не деньги.
