## Важно про измерение

UTM-метки сами по себе не считаются: нужен счётчик на странице. Сейчас аналитики на лендинге нет.
Варианты: Яндекс.Метрика (нужен номер счётчика из аккаунта) или собственный клик-трекер
(`links-tracker.valdislav-n.workers.dev` из `content-factory`), который умеет считать клики
по коду ссылки. Без этого видно только клики в отчётах Travelpayouts (по партнёрским ссылкам).
