# Pinterest через RSS

Pinterest не умеет импортировать RSS сам. Создание пинов через API у нас
заблокировано (403 code 29 — приложение на Trial, продакшн-пины недоступны).
Рабочий обход — сервис-посредник, который читает RSS и создаёт пины за тебя.

## Что готово

- Фид: `https://valdislavn-spec.github.io/content-factory/feed.xml`
- 10 гидов, у каждого картинка 1000×1500 в `enclosure` и `media:content`
- Ссылка в элементе ведёт на гид, а не на канал — Pinterest не режет за спам

## Подключение (10 минут, один раз)

### Вариант A — IFTTT

1. `ifttt.com` → Create → If This → **RSS Feed** → «New feed item».
2. URL фида: `https://valdislavn-spec.github.io/content-factory/feed.xml`.
3. Then That → **Pinterest** → «Pin image» (нужно связать аккаунт).
4. Доска: `Travel on a budget`.
5. В поле описания подставь `{{EntryTitle}} — {{EntryContent}}` (или оставь заголовок).

IFTTT проверяет фид раз в 15–60 минут и публикует новые элементы. Старые не
трогает, поэтому 10 текущих гидов зальются один раз.

### Вариант B — Zapier / Make

Zap: **RSS by Zapier → Pinterest**. Те же три поля: URL фида, доска, описание.
У Make есть готовый шаблон «RSS to Pinterest», бесплатный тариф — 1000 операций.

## Что важно

- **Не включай мгновенную заливку всех 10 пинов сразу** — Pinterest подозрительно
  относится к всплескам. Лучше интервалом: 1 пин в день.
- Фид обновляется при каждом деплое, `pubDate` идёт по убыванию — новые гиды
  окажутся сверху и уедут первыми.
- Если добавишь новый гид в `ITEMS` в `scripts/build_feed.py`, он попадёт в фид
  автоматически после пуша.

## Проверка

Открой фид в браузере — должен отдаться XML с 10 `<item>`. Валидатор:
`validator.w3.org/feed/` — там же покажет ошибки, если появятся.
