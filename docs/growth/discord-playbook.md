# Discord: автоматизация и набор подписчиков

Дата: 15.11.2026. Цель — не просто зеркалить Telegram в Discord, а получать
из Discord переходы в Telegram-каналы и удерживать новую аудиторию.

## 1. Структура сервера

Рекомендуемая раскладка (один webhook = один канал):

| Telegram-канал | Discord-канал | Webhook-секрет |
|---|---|---|
| `sport-news` | `#us-sports` | `DISCORD_WEBHOOK_URL_SPORT_NEWS` |
| `ai-news` | `#ai-news` | `DISCORD_WEBHOOK_URL_AI_NEWS` |
| `crypto-news` | `#crypto` | `DISCORD_WEBHOOK_URL_CRYPTO_NEWS` |
| — | `#announcements` | только ручные посты |
| — | `#welcome` | приветствие + правила |
| — | `#feedback` | обратная связь |

Общий `DISCORD_WEBHOOK_URL` — только fallback. Если оставить один webhook на
три канала, спорт, ИИ и крипта смешаются в одной ленте: это снижает удержание
и кликабельность.

## 2. Что уже автоматизировано

- `content-factory-cloud-en-es` публикует посты трёх английских каналов в
  Discord по расписанию.
- `content_factory/publishers/discord.py` конвертирует HTML в Discord Markdown,
  добавляет CTA и ссылку на Telegram, не пингует `@everyone`, при наличии
  картинки прикрепляет embed.
- `discord-check` ежедневно проверяет webhook через GET + тестовый POST и
  удаляет сообщение.
- Для каждого канала можно задать отдельный webhook-секрет; суффикс имеет
  приоритет над общим.

## 3. Воронка Discord → Telegram

1. **Пост в Discord** заканчивается CTA и ссылкой на Telegram.
2. **Закреп в каждом тематическом канале** — короткий пост «что здесь есть»
   и ссылка на Telegram.
3. **Welcome-канал** — три кнопки-ссылки: спорт, ИИ, крипта.
4. **Еженедельный дайджест** — лучший пост недели в `#announcements` со
   ссылкой на Telegram-канал.
5. **Приглашения** — отдельные invite-ссылки для Telegram, X, Reddit и
   партнёров, чтобы понимать источник. Discord показывает статистику
   использований инвайта.

Шаблон закрепа:

```text
📌 US Sports — каждый день
NFL, NBA, MLB, NHL и college football: счёта, обмены, травмы и разборы.

→ Telegram: https://t.me/SPORTNews0007
```

## 4. Метрики, которые надо смотреть

- переходы Discord → Telegram (UTM/инвайты, где возможно);
- новые подписчики Telegram за неделю;
- удержание: доля подписчиков, которые остались через 7 дней;
- реакции/ответы в Discord на тематический пост;
- доля постов, которые получили хотя бы один клик.

Если CTA не даёт переходов 2 недели подряд — менять не частоту, а оффер:
«что человек получит в Telegram, чего нет в Discord».

## 5. Ритм публикаций

- Discord — не более 8–12 постов в день на тематический канал;
- если расписание даёт больше, включать дайджест раз в 3–4 поста;
- лучше 1 сильный пост с CTA, чем 3 подряд без реакции;
- закреп и welcome обновлять раз в месяц.

## 6. Чек-лист запуска

- [ ] Создать три текстовых канала в Discord.
- [ ] Создать три webhook и положить в GitHub Secrets.
- [ ] Запустить `discord-check` вручную, проверить `channel_id`.
- [ ] Добавить закрепы и welcome-ссылку на Telegram.
- [ ] Проверить, что в `publishes` появился `publisher='discord'`.
- [ ] Через 7 дней сравнить переходы и подписчиков.
