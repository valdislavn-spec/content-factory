# Операционный агент (ops-agent)

Многофункциональный агент, который сам делает ежедневную рутину и присылает
короткую сводку в Telegram. Работает **без внешних agent-фреймворков** и на
**бесплатном Gemini**, поэтому почти не тратит токены: один запуск в день,
2–4 коротких LLM-вызова.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `channels` | список каналов сети: id, title, язык, постов/день, @username |
| `growth` | запускает `scripts/growth_report.py` и отдаёт свежие метрики |
| `preview` | публичное превью канала: подписчики и последние посты |
| `health` | последние запуски GitHub Actions контент-завода |
| `budget` | расход LLM-запросов/токенов за сутки |
| `promo` | статус ВП-трекера и пакета каталогов |
| `notes` | поиск по документации репозитория |

Агент читает данные и пишет сводку; ничего не публикует и не удаляет.

## Токен-экономия

- `--max-steps 6` — не больше 6 инструментов за запуск.
- `--max-tokens 480` — короткие ответы модели.
- Наблюдения инструментов обрезаются до 900 символов.
- Модель — `gemini` (AI Studio free tier), резерв — `pollinations` (без ключа).
- Если LLM недоступна вообще — печатается детерминированная сводка без токенов.

## Запуск

```bash
# локально (нужен GEMINI_API_KEY; из РФ — VPN/Actions)
python -m content_factory.agents.ops_agent
python -m content_factory.agents.ops_agent --send

# свободная задача
python -m content_factory.agents.ops_agent --task "проверь промо и метрики"
```

В GitHub: **Actions → ops-agent → Run workflow** (поле `task` можно оставить
пустым), либо по расписанию в 09:20 UTC. Сводка уходит в `TELEGRAM_ALERT_CHAT_ID`.

## Как расширить

Добавьте функцию-инструмент в `content_factory/agents/tools.py` и запись в
`TOOLS` с коротким описанием: агент сам увидит его в промпте. Требование —
возвращать компактный dict/list и не делать опасных действий.
