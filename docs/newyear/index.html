Как считали

  1. Цена — итоговая цена пакета (price) на 2 взрослых; на человека — price/2; за человека за ночь — price/2/nights.
  2. Качество — рейтинг отеля из отельной базы Travelata (0–5). Для направления — средний рейтинг отелей страны в базе (data/raw/hotels.json).
  3. Цена за балл рейтинга (предложение) = ₽ за человека за ночь / рейтинг отеля; меньше — лучше. В рейтинг попадают только отели с рейтингом ≥ 4,0.
  4. Цена за балл рейтинга (направление) = медианная ₽ за человека за ночь / средний рейтинг базы, только для направлений с ≥ 3 предложениями.

Рейтинг есть у ~9,5% отелей базы, поэтому в рейтинг попадают только предложения с оценкой. Рейтинг Travelata — оценка отеля, а не звёздность; звёздность показана отдельно.
