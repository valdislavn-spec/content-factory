заказчика: пик — каждый час, день — 90–105 мин, ночь — 140 мин (дайджест).

## Сетка по регионам (локальное время каналов)

Часовые пояса: US — UTC-5 (Нью-Йорк), LatAm — UTC-6 (Мехико). Каналы внутри
ветки сдвинуты на 0/10/20 и 0/15/30 минут, чтобы посты не выходили одновременно.

**Ночь (дайджест ≤900 символов, каждые 140 мин):**
23:00, 01:20, 03:40 — с учётом высоких просмотров около полуночи.
Окно 06:00 исключено как «мёртвая зона» по данным LiveDune.

**Утро (новости/дайджест, пик):**
US: 08:00, 09:00 · LatAm: 08:00, 09:00 (лучшее окно новостей 08:00–09:00).

**Обед (пик):**
US: 12:00, 13:00 · LatAm: 13:00, 14:00 (13:00–16:00 — окно обеда).

**День (обычный режим, ~100 мин):**
US: 07:00, 10:20, 17:00 · LatAm: 07:00, 10:40, 15:40, 17:20
(обходятся «мёртвые зоны» 06:00 и 14:00–16:00 по будням).

**Вечер (пик, каждый час):**
US: 18:00–22:00 · LatAm: 19:00–22:00 — главный пик активности, сюда ставим
analysis и interactive (`publishers.telegram.photo_card` не влияет).

## Текст под фазу

| Фаза | Формат | Микс |
|---|---|---|
| ночь (23:00–07:00) | только `digest` | короткий, ≤900 символов |
| пик (утро/обед/вечер) | story/analysis/interactive | 20/40/40 + блок трендов в начале |
| день | story/analysis/interactive | 30/40/30 |

Тренды в начале поста (пиковые часы): Google Trends RSS (US/MX),
CoinGecko Trending, GitHub Trending, Hacker News, локальная частота терминов.
Кэш 30 минут, фильтр по тематике канала (`content_factory/trends.py`).

## Выходные

Статистика LiveDune показывает другую картину в выходные (выше ночная и
вечерняя активность). Сейчас у каналов один ежедневный ритм; отдельное
расписание на выходные — следующий шаг (поле `weekend_schedule`).

## Стиль постов (с 07.11.2026)

- Пишем **как профессиональный журналист**: заголовок, лид (что случилось),
  2–3 коротких абзаца прозы. Без ярлыков «Ключевые моменты», «Почему это
  важно», «В тренде» — и без нумерации пунктов.
- **Эмодзи**: 1–3 уместных смайлика в посте (тематический в начале, эмодзи у
  пунктов дайджеста), без «ёлки» из символов.
- **SEO**: главный ключ в заголовке и лиде; хэштеги — тематические + из трендов
  и ключевых терминов (`#OpenAI`, `#AIFunding`); тексты без канцелярита и без
  обрезанных служебных вставок.
- **Тренды** используются как темы для выбора сюжета и SEO-ключей, а не как
  отдельная строка «Trending now».
- Ночной режим — короткий дайджест (≤900 симв.), днём — микс story/analysis/
  interactive (пик: 20/40/40, день: 30/40/30).
