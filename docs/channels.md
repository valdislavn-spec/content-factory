# Каналы: темы, источники, расписание

Все каналы описаны в `config/channels.yaml`. Этот файл — «редакционный план»:
тема, ключевые слова, источники, время публикации, тон и формат постов.
Токены и id каналов в нём **не хранятся** — они в `.env`.

Шесть каналов уже настроены. Их можно менять, выключать (`enabled: false`) и
добавлять новые.

### Как читать таблицу

- **id** — техническое имя; используется в командах `--channel`.
- **Источники** — фактический список из `channels.yaml`; у каждого есть `id`,
  `type` (`rss`/`web`/`telegram`), `url`, `weight` (вес при ранжировании).
- **Форматы** — какие типы постов разрешены:
  - `digest` — подборка нескольких новостей/событий дня;
  - `story` — один сюжет, короткий пересказ;
  - `analysis` — разбор с ракурсами из разных источников.
- **Тон** — `expert` (сухо, по делу), `science` (аккуратно, со ссылками на
  исследования), `friendly` (проще, дружелюбнее).

## 2. Тематические ключевые слова (`topics`)

Отбор новостей идёт по вхождению ключевых слов в заголовок/текст. В конфиге
используются **основы слов**, чтобы ловить все формы:

```yaml
topics:
  - технологи      # технологии, технологический, технологиях
  - нейросет       # нейросеть, нейросети, нейросетей
  - ИИ
```

Правила:

- Основа должна быть достаточно длинной (5+ букв), иначе будет много ложных
  срабатываний.
- Регистр не важен.
- Список стоит держать в 15–50 слов: слишком короткий — мало новостей,
  слишком длинный — мусор. Начните с 15–20 профильных слов и расширяйте,
  если канал пропускает свежие сюжеты.
- Для канала с узкой темой добавьте специфичные слова, а общие («новости»,
  «россия») — не добавляйте.

`exclude_keywords` — слова-исключения: если новость их содержит, она
отбрасывается. По умолчанию у всех каналов исключены «реклама», «гороскоп»,
«казино» (у каждого набора — свои).

## 3. Источники

Три типа:

| Тип | Как работает | Пример |
|---|---|---|
| `rss` | скачивается RSS/Atom-лента, разбираются записи | `https://habr.com/ru/rss/news/?fl=ru` |
| `web` | скачивается HTML-страница, извлекается текст | страница со списком новостей |
| `telegram` | чтение публичного канала через Telethon (опционально) | `https://t.me/rian_ru` |

Пример источника:

```yaml
sources:
  - id: habr-news
    type: rss
    url: https://habr.com/ru/rss/news/?fl=ru
    name: Habr
    weight: 1.2
```

- `weight` — насколько источник важен: 1.0 — обычный, 1.2–1.3 — надёжный и
  тематичный, 0.7–0.9 — шумный/широкий (например, общая лента Lenta.ru).
- `enabled: false` — временно отключить источник, не удаляя.
- `options` — дополнительные параметры адаптера. Для узких тем полезен
  `trust: true`: например, N+1 и Naked Science целиком про науку, и их статьи
  не нужно дополнительно фильтровать по ключевым словам:

| Тип | Опция | Смысл |
|---|---|---|
| `rss` | `max_items` | сколько записей ленты брать (по умолчанию 30) |
| `rss` | `full_text` | `true` — скачивать полный текст каждой статьи (медленнее, но точнее резюме) |
| `web` | `link_regex` / `link_contains` | фильтр ссылок по регулярному выражению/подстроке |
| `web` | `max_items`, `full_text` | как у RSS |
| `web` | `same_domain` | `false` — разрешить ссылки на другие домены (по умолчанию только свой) |
| `telegram` | `limit` | сколько последних сообщений читать (по умолчанию 30) |
| любой | `trust` | `true` — тематический источник: его лента принимается без жёсткого фильтра по ключевым словам (стоп-слова канала действуют) |

Например, включить полный текст статей RSS (полезно для science-health):

```yaml
- id: nplus1
  type: rss
  url: https://nplus1.ru/rss
  name: N+1
  weight: 1.3
  options: {max_items: 20, full_text: true}
```

### Telegram-источники

По умолчанию Telegram-каналы как **источники** отключены: для них нужна
опциональная зависимость Telethon и пользовательская сессия. Публикация же в
Telegram работает через обычный Bot API без Telethon.

Чтобы включить:

1. Установите Telethon:
   `./.venv/bin/python -m pip install -r requirements-optional.txt`
2. Получите `api_id`/`api_hash` на <https://my.telegram.org> (бесплатно).
3. Пропишите в `.env`: `TG_API_ID`, `TG_API_HASH`, `TG_SESSION`.
4. В `channels.yaml` у нужного источника поставьте `enabled: true`:

```yaml
- id: tg-ria-tech
  type: telegram
  url: https://t.me/rian_ru
  name: РИА Новости (Telegram)
  enabled: true
  options: {limit: 30}
```

5. При первом запуске Telethon попросит номер телефона и код — сессия
   сохранится в файл (`TG_SESSION`). **Храните его как пароль**: он даёт
   доступ к аккаунту.

## 4. Расписание (`schedule`)

Формат — список `"HH:MM"` по московскому времени:

```yaml
schedule: ["09:00", "13:00", "19:00"]
posts_per_day: 3
```

- Время — МСК; для другого пояса используйте `timezone_offset` (например,
  `4` для Самары, `5` для Екатеринбурга).
- Число слотов обычно равно `posts_per_day`; больше слотов, чем постов, —
  нормально (демон выберет первые доступные).
- Не ставьте слоты слишком близко (менее 30 минут) — аудитория не любит
  «пулемёт», а Telegram может ограничить частоту.
- Слот считается отработанным после обработки (в dry-run — когда пост попал
  в outbox). Если процесс не смог выполнить слот целиком (например, ошибка
  базы), отметка не ставится и слот повторится в следующем цикле. Ошибки
  отдельных публикаций (нет прав бота, 429) слот не откатывают — они видны в
  `publishes.error` и отчёте (см. [operations.md](operations.md)).

## 5. Тон, формат, длина

```yaml
tone: expert            # expert | science | friendly
emoji: true             # добавлять ли эмодзи
formats: [digest, story, analysis]
max_post_chars: 3500    # лимит Telegram — 4096 символов
hashtags: ["#технологии", "#ИИ", "#наука"]
cta: "Больше разборов — в нашем канале."
```

- `tone` влияет на стиль генерации (в extractive-режиме — на шаблоны).
- `formats` — разрешённые форматы; чем их больше, тем разнообразнее лента.
- `max_post_chars` держите не больше 4000: Telegram ограничивает сообщение
  4096 символами.
- `cta` — призыв к действию в конце поста; пустая строка = без CTA.
- `hashtags` — автоматически добавляются в пост.

### Куда публиковать: Telegram и VK

По умолчанию канал публикуется только в Telegram (`publisher_ids:
[telegram]`). ВКонтакте уже реализован — включите его у нужного канала:

```yaml
publisher_ids: [telegram, vk]
```

и заполните в `.env`:

```bash
VK_ACCESS_TOKEN=токен_группы   # права wall, manage
VK_GROUP_ID=123456789          # числовой id сообщества
```

Публикатор ВК отправляет очищенный текст (ВК не понимает HTML) и режет его по
лимиту 16 000 символов. В dry-run реальные отправки не выполняются: пост
попадает в outbox независимо от `publisher_ids`. Ошибки ВК не роняют
публикацию в Telegram — они фиксируются отдельно в `publishes`.

## 6. Как изменить канал

1. Откройте `config/channels.yaml`.
2. Измените поля у нужного канала (например, добавьте источник или
   поменяйте время).
3. Проверьте конфиг:

```bash
./.venv/bin/python -m content_factory channels
```

4. Сделайте пробный прогон без публикации:

```bash
./.venv/bin/python -m content_factory run --channel tech-ai --dry-run
```

5. Перезапустите демон, если он работает.

**Важно:** после правки YAML перезапускайте процесс — демон читает конфиг при
старте. Опечатка в YAML приведёт к понятной ошибке при загрузке (пути и номера
каналов указываются в тексте ошибки).

## 7. Как добавить седьмой канал

1. Скопируйте блок любого канала в `config/channels.yaml`.
2. Задайте уникальный `id` (латиница, цифры, `-`/`_`, например `sport`).
3. Заполните `title`, `description`, `topics`, `exclude_keywords`.
4. Перечислите `sources` (можно начать с 2–3 RSS).
5. Задайте `schedule`, `formats`, `tone`, `hashtags`.
6. Добавьте в `.env` переменную с id канала:

```bash
TELEGRAM_CHAT_ID_SPORT=@my_sport_channel
```

Имя переменной строится из id: заглавные буквы, дефисы → подчёркивания
(`sport-news` → `TELEGRAM_CHAT_ID_SPORT_NEWS`). Альтернатива — прописать
`telegram_chat_id` прямо в YAML, но тогда id канала попадёт в git.

7. Создайте канал в Telegram и добавьте бота администратором.
8. Проверьте:

```bash
./.venv/bin/python -m content_factory channels
./.venv/bin/python -m content_factory sources check
./.venv/bin/python -m content_factory run --channel sport --dry-run
```

9. Посмотрите посты в `data/outbox/`, затем публикуйте.

## 8. Как выключить канал

```yaml
enabled: false
```

Демон его пропустит, данные и настройки останутся. Полностью удалять канал не
нужно.

## 9. Что делает канал «хорошим»

- 15–50 точных ключевых слов темы (начните с 15–20 профильных).
- 3–6 источников с разумными весами, минимум 2–3 независимых.
- Слоты в то время, когда аудитория читает (утро/обед/вечер).
- Разные форматы, а не только `story`.
- Регулярная проверка ленты: мусорные новости → правим `exclude_keywords`
  и веса источников.
