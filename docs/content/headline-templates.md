# Шаблоны заголовков для A/B (EN + ES)

Правило: меняем один элемент за раз; 5 постов на вариант; смотрим пересылки и ER,
а не только просмотры (просмотры у малых каналов почти одинаковые).

## Варианты (EN)

1. **Цифра**: `{Asset} {движение} {цифра}: что это значит для {аудитория}`
   → «Bitcoin ETFs pulled in $2.4B this week — what it means for price»
2. **Польза**: `Как {событие} влияет на {область}` → «How the SEC ruling changes
   crypto custody in the US»
3. **Вопрос**: `Почему {явление}?` → «Why is Ethereum supply shrinking?»
4. **Цитата/заявление**: `{Кто}: "{цитата}"` → «BlackRock: "Bitcoin is now a
   mainstream allocation"»
5. **Список**: `{N} {вещей}, которые {результат}` → «3 charts that explain the
   latest crypto rally»
6. **Предупреждение (без кликбейта)**: `Что изменится после {событие}` →
   «What changes for crypto traders after Jan 1»

## Варианты (ES)

1. `{Activo} {movimiento} {cifra}: qué significa para {audiencia}`
2. `Cómo {evento} afecta a {área}`
3. `Por qué {fenómeno}?`
4. `{Quién}: "{cita}"`
5. `{N} gráficos que explican {tema}`

## План A/B на 2 недели (crypto-канал EN)

| Неделя | Вариант A (пн–ср) | Вариант B (чт–сб) | Метрика |
|---|---|---|---|
| 1 | Цифра в начале | Польза («как это влияет») | пересылки + ER |
| 2 | Вопрос | Цитата/заявление | подписки за 48 ч |

Фиксация: таблица `дата | заголовок | вариант | просмотры | пересылки | ER`.
Победивший стиль — в промпт генератора (пост «профессиональный журналист»,
без ярлыков «Почему это важно»).

## Ограничения

- Заголовок ≤ 90 символов (виден в превью).
- Ключевое слово канала — в первом абзаце, не обязательно в заголовке.
- Без CAPS, без «шок», «срочно», «100%».
