Pay per quote, not per seat: an x402 use case for AI agents on Solana

A submission for the Swap.io x402 use-case bounty on Superteam Earn.

The pitch

AI agents are becoming real economic actors, but our billing stack was built for humans: signup forms, sales calls, API keys, monthly seat licenses. An autonomous agent cannot fill out a form — and a bot that trades a few times a day should not pay for a monthly plan it mostly does not use.

Meet SwapBot

A Telegram bot with one job: “swap 2 SOL → USDC”.

  1. The user sends a swap request.
  2. The bot asks Swap.io's Agent API for a quote.
  3. The API replies 402 Payment Required — 0.001 USDC.
  4. The bot signs the x402 payment, receives the signed quote, and executes the swap.
  5. The bot keeps a 1% fee. Every quote it consumes is metered and paid for.

Why x402 wins here

  • No API keys. The wallet is the credential — nothing to leak or rotate.
  • Pay per call. 0.001 USDC per quote, no minimums, no seats.
  • Agent-to-agent. Any agent can pay any API. That is composable by default on Solana.

Unit economics

10,000 users × 20 swaps per month × $0.001 per quote = $200 of API cost, versus $2,000+ in typical seat licenses. The margin is the product.
