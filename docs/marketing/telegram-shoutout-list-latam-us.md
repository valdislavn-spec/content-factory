## Как покупать (чеклист аутрича)

1. Написать админу (@username из bio канала или contact), спросить:
   - цена поста 24 ч / 48 ч и формат (текст + ссылка, без закрепа vs с закрепом);
   - свежая статистика: подписчики, охват поста (views), ER;
   - гео-разбивка: доля MX / AR / CO / ES / US;
   - разрешён ли tracking-link (наш `links-tracker.valdislav-n.workers.dev`);
   - условия: предоплата/постоплата, удаление, возврат при недоборе просмотров.
2. Ориентир по цене: для ES-каналов 100–200k подписчиков пост обычно $30–150;
   CPM по факту просмотров ≈ $0.9–3. Верхние EN-каналы (Watcher Guru, Cointelegraph)
   — от $1–5k за пост, для теста не брать.
3. Первый тест: 3–5 каналов × $50–100, разные креативы, UTM/`links-tracker`,
   сравнивать подписки по `?start=` или по переходу с tracking-ссылки.
4. Не платить панелям «накрутки» и каналам без живых просмотров: проверять
   views/подписчики ≥ 10–20%, комментарии, дату последних постов.
5. Для futbol-es / crypto-es — старт с @chiringuitotelegram, @buzzfutbol,
   @telonews_es, @criptonoticias; для crypto-news (EN) — @coinmarketcap.
