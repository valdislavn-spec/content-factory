## Что реально даёт базу

1. **Кросс-промо из своего крипто-канала (3 375 чел.)** — единственный бесплатный объём. Аудитория платёжеспособная и много путешествует; пост с оффером → лендинг → форма → Kit (двойное подтверждение).
2. **Платные размещения**: 19 каналов из `leads-ai-tech.csv` — это AI/крипто-тематика; для travel нужен отдельный список travel-каналов (могу собрать: каналы «путешествия/дешёвые билеты/туры» 20–100K, у большинства есть контакт админа).
3. **Pinterest**: 4 пина уже стоят, но токен истёк — без него не собрать статистику и не добавить пины. Нужен новый access token.
4. **Собственные формы**: на 16 страницах стоит наша форма → D1 → Kit. Пока трафика мало (TRAVEL 2 подписчика, 12 в Bluesky).
