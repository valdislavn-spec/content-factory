Политика конфиденциальности дайджеста

Обновлено 15.11.2026

Какие данные собираем

Только email-адрес, который вы сами указываете в форме подписки, метку страницы-источника и язык страницы (ru/en). Платёжные данные, данные о бронировании и документы мы не получаем и не храним.

Зачем

Чтобы отправлять еженедельный дайджест со сводкой цен на пакетные туры и промо партнёров. Других писем на этот адрес не шлём, адрес никому не передаём.

Где хранятся данные

В Cloudflare D1 (Cloudflare, Inc.). Доступ к списку — только у владельца проекта по токену. Переходы по партнёрским ссылкам считаются обезличенно: счётчик кликов по короткому коду, без профилирования.

Как отписаться и удалить данные

В каждом письме есть ссылка «Отписаться» — срабатывает сразу. Полное удаление: письмо на valdislav.n@gmail.com с темой «удалить email» — удалим в течение 48 часов.

Партнёрские ссылки

На страницах и в письмах есть партнёрские ссылки (Aviasales, Tiqets, Kiwitaxi, Saily, Localrent и др.). При покупке по ним мы можем получить комиссию; цена для вас не меняется, условия покупки определяет партнёр.
